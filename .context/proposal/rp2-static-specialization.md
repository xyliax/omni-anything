# RP2：静态图特化

更新：2026-08-06

状态：**初步设想；目前没有细想，尚未形成可提交的研究点。**

## 暂定方向

利用双工前台中重复、可预测的执行形状，探索静态计算图或 AOT 执行特化，以减少动态规划、kernel launch、内存准备或 shape 处理的固定开销。

这只是一条工作假设。当前尚未确定：

- 应特化的准确对象是 micro-prefill、完整前台一 tick、混合 batch signature，还是其他执行单元；
- 哪些形状在真实的 Thinking Machines Lab（TML）交互模型负载中足够稳定且高频；
- 最强现有引擎 baseline 已覆盖到哪里；
- 相对现有 CUDA graph、piecewise graph、shape bucketing 或编译路径的真实差距；
- 预期收益、适用硬件、实现复杂度和验证实验。

## 表述纪律

- 不沿用旧说明中「机制已成立」或「现有引擎覆盖不到」的结论。
- 在完成负载定义、已有工作刷新和最小测量前，不声称新颖性或性能收益。
- 与 RP1 的关系尚未定义；不得为了凑三点而强行绑定。
