- **Title:** Laminar: A Scalable Asynchronous RL Post-Training Framework
  **标题:** Laminar: A Scalable Asynchronous RL Post-Training Framework
- **Summary:** Laminar makes RL post-training asynchronous at the trajectory level: trajectories finish independently, trainer consumes completed experiences from a buffer, relay workers handle weight updates, and dynamic repack reduces rollout long-tail bubbles.
  **一句话总结:** Laminar 把 RL post-training 的异步粒度推进到 trajectory 级：trajectory 独立完成，trainer 从 buffer 消费已完成经验，relay worker 负责权重更新，dynamic repack 缓解 rollout 长尾空泡。
- **Paper Type:** RL / rollout infrastructure system
  **论文类型:** RL / rollout 基础设施系统
- **Venue:** arXiv v1, 2025-10-14; EuroSys 2026 accepted paper
  **发表:** arXiv v1，2025-10-14；EuroSys 2026 accepted paper
- **Authors:** Guangming Sheng, Yuxuan Tong, Borui Wan, Wang Zhang, Chaobo Jia, Xibin Wu, Yuqi Wu, Xiang Li, Chi Zhang, Yanghua Peng, Haibin Lin, Xin Liu, Chuan Wu
  **作者:** Guangming Sheng、Yuxuan Tong、Borui Wan、Wang Zhang、Chaobo Jia、Xibin Wu、Yuqi Wu、Xiang Li、Chi Zhang、Yanghua Peng、Haibin Lin、Xin Liu、Chuan Wu

  **资源:** [arXiv](https://arxiv.org/abs/2510.12633)；[EuroSys 2026 accepted papers](https://2026.eurosys.org/papers.html)

- ## Orientation
    - **English:** Laminar targets the long-tail rollout bottleneck in LLM RL post-training. Generation dominates training time, and trajectory lengths or environment delays can be highly skewed.
      **中文:** Laminar 针对的是 LLM RL post-training 里的 rollout 长尾瓶颈。生成阶段占主要时间，而 trajectory 长度和环境延迟可能非常长尾。
      evidence:: E1, E2
    - **English:** Existing async systems still rely on global weight synchronization or partial rollout. Laminar removes this global lockstep and lets each trajectory proceed at its own pace.
      **中文:** 现有 async 系统仍然依赖全局权重同步或 partial rollout。Laminar 去掉这个全局节奏，让每条 trajectory 按自己的速度推进。
      evidence:: E3, E4
    - **English:** The paper is not about streaming video context, but it is directly relevant to staleness, rollout long tail, and policy-version consistency.
      **中文:** 这篇不是 streaming video context 论文，但它和 staleness、rollout 长尾、policy version 一致性直接相关。

- ## Quick Reference
    - **English:** Rollout unit: one complete trajectory generated by one policy version.
      **中文:** Rollout 单位：一条由单一 policy version 生成的完整 trajectory。
      evidence:: E2, E8
    - **English:** Trainer input: completed trajectories sampled from the experience buffer.
      **中文:** Trainer 输入：从 experience buffer 采样出来的已完成 trajectories。
      evidence:: E5
    - **English:** Algorithm in experiments: GRPO with rule-based reward; 512 prompts, 16 responses each, global batch size 8192.
      **中文:** 实验算法：GRPO + rule-based reward；512 个 prompts，每个 16 个 responses，global batch size 8192。
      evidence:: E9
    - **English:** Architecture: trainer GPUs and rollout GPUs are disaggregated; CPU relay workers manage weight synchronization.
      **中文:** 架构：trainer GPUs 和 rollout GPUs 分离；CPU relay workers 负责权重同步。
      evidence:: E5, E6
    - **English:** Long-tail fix: dynamic repack consolidates unfinished trajectories from underutilized rollouts onto fewer destination rollouts within the same policy-version group.
      **中文:** 长尾处理：dynamic repack 在同一 policy-version group 内，把低利用 rollout 上未完成的 trajectories 合并到少数 destination rollouts。
      evidence:: E7

- ## Mechanism and Design
    - **English:** Relay workers act as a distributed parameter service. The actor sends weights to a master relay, the master broadcasts to per-machine relays via RDMA, and rollouts pull locally via PCIe.
      **中文:** Relay worker 相当于分布式参数服务。actor 把权重发给 master relay，master 通过 RDMA 广播到各机器 relay，rollout 再通过 PCIe 从本机 relay 拉权重。
      evidence:: E6
    - **English:** The data module separates prompt pool, partial response pool, and experience buffer. The partial response pool is important for recovery.
      **中文:** Data module 分成 prompt pool、partial response pool 和 experience buffer。partial response pool 对故障恢复很重要。
      evidence:: E5
    - **English:** Repack uses KVCache utilization as an online idleness signal, avoiding task-specific offline profiling.
      **中文:** Repack 用 KVCache utilization 作为在线 idle 信号，避免为每个任务离线调阈值。
      evidence:: E7
    - **English:** Inherent staleness is defined per trajectory as the actor-version gap at completion time, not as a configured global bound.
      **中文:** inherent staleness 是每条 trajectory 完成时的 actor-version 差，而不是预先配置的全局 bound。
      evidence:: E8

- ## Technical Judgment
    - **English:** Laminar is a strong system baseline for claims about rollout long tails and staleness. It shows why fixed-ratio resource allocation and global synchronization can fail at scale.
      **中文:** Laminar 是讨论 rollout 长尾和 staleness 时必须看的系统 baseline。它说明固定配比资源和全局同步为什么会在大规模下失效。
      claim_kind:: analyst_assessment
    - **English:** Its critique of partial rollout is especially useful: interrupting generation can waste KV work and create mixed-policy trajectories.
      **中文:** 它对 partial rollout 的批评尤其有用：中断生成会浪费 KV 相关工作，并制造 mixed-policy trajectory。
      claim_kind:: analyst_assessment
    - **English:** Its limitation for our project is also clear: it does not define how streaming context becomes a training sample.
      **中文:** 它对我们项目的边界也很清楚：它没有定义 streaming context 如何变成训练样本。
      claim_kind:: analyst_assessment
