Title:

Pilarius: Memory Multiplexing through Cyclic State Restoration for Interactive Model Serving

Abstract:

Emerging interaction models sustain long-lived full-duplex sessions, in which input and output overlap, and advance them in fixed-duration micro-turns: in each micro-turn, the model ingests the input accumulated since the previous one, determines both response content and timing, and may decode a bounded output segment for real-time delivery. Between updates the session performs no model computation, while its retained KV state persists and grows from one micro-turn to the next. This creates a residency dilemma: full residency lets concurrent sessions exhaust GPU memory while compute slack remains, whereas reactive offloading places restoration on the next update's critical path. The update schedule, however, is a property the workload commits in advance: when a session's state will next be needed is known before the demand arrives, cycle after cycle. We present Pilarius, a serving system that supports memory multiplexing through cyclic state restoration, without truncating the history retained by the application. Pilarius evicts recoverable state after an update and restores it before the session's next scheduled update; eviction depth is bounded by the volume that the shared transfer link can recover within the intervening KV-idle interval. At admission, Pilarius assigns each session a fixed phase within the update period, spreading restoration deadlines and residency peaks across the period. Pilarius serves heterogeneous sessions under a common plan: sessions with larger restoration demand retain more state on the GPU, and a new session is admitted only when a feasible phase is available. Our evaluation shows that Pilarius serves XX times as many concurrent sessions as full-residency serving and YY times as many as the strongest existing baseline under the same service objective and matched generation work.
