# Twelve-Page Budget

EuroSys 2027 allows at most 12 pages of technical content, with unlimited additional pages for references. This is a planning budget, not permission to alter the official template.

| Section | Target pages | Purpose |
| --- | ---: | --- |
| Abstract + Introduction | 1.50 | Problem, running example, key idea, contributions |
| Periodic Interactive Model Serving | 1.50 | Workload, observation, resource frontier |
| Conveyor Design | 3.00 | Unified design and three mechanism modules |
| Implementation | 1.00 | System realization and observability |
| Evaluation Methodology | 0.75 | Questions, controls, workloads and metrics |
| Evaluation | 3.00 | Main result, cost, ablations, generalization |
| Related Work | 0.75 | Closest capability-level comparison |
| Discussion and Limitations | 0.35 | Boundaries and failure regimes |
| Conclusion | 0.15 | Supported takeaway only |
| **Total technical content** | **12.00** | References follow without a fixed page limit |

If the draft exceeds this budget, cut scope or prose. Do not change font size, line spacing, margins, column gap, caption size or class internals.
