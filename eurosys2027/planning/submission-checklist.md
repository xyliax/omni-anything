# EuroSys 2027 投稿检查

官方依据：[Call for Papers](https://2027.eurosys.org/cfp.html)，核验日期 2026-09-25。规则以官网和投稿系统为准；本清单不记录注册或提交是否完成。

秋季轮摘要截止 2026-09-17、全文截止 2026-09-24，均为 AoE。

## 格式与匿名

- [ ] 正文技术内容不超过 12 页；参考文献可额外增加，补充材料单独上传，正文自包含。
- [ ] A4 或 Letter；内容区域 178 × 229 mm，双栏间距至少 8 mm。
- [ ] 所有文字（含图与图注）至少 10pt、行距至少 12pt；灰度下无需放大即可阅读，每页编号。
- [ ] 使用未压缩版式的模板；推荐 SIGPLAN，锁定来源见 [UPSTREAM.md](../vendor/acmart/UPSTREAM.md)。
- [ ] PDF、元数据、引用、链接与图中均无身份泄漏；省略致谢，自引使用第三人称。

## 内容与披露

- [ ] [恢复分配决策](../../docs/system.md#group-restoration-allocation)与[计划修正](../../docs/system.md#planning-updates)已按作者授权选定；提交前核验实现与测量，并复核 Design 正文、图件和评估的一致性。
- [ ] 每项贡献与已实现、已验证的内容一致；最近工作比较有原始引用。
- [ ] 模型推导、诊断观察和正式结果分清；失败配置、代价与证据边界完整。
- [ ] 原创性、并行投稿、相关稿件与 ACM 政策已核对；每作者每轮至多 3 篇投稿。
- [ ] 按规则披露 AI 使用，最终表述由作者确认。

## 最终文件

- [ ] `make check` 通过，并人工确认正文页数及参考文献起点。
- [ ] PDF 字体嵌入，图件和公式可读；无占位、TODO 或作者备忘。
- [ ] 投稿系统的版本、附件与作者信息核对完成。
