\begin{abstract}
Serving full-duplex interaction models requires maintaining ongoing sessions in which input and output can overlap.
In periodic service, each update processes new input and generates output as needed, while historical key--value (KV) state persists between updates.
As contexts grow, keeping this state on the GPU can exhaust memory while the combined work of admitted sessions still leaves time within each period.
Offloading idle KV frees capacity, but restoring it only when the next update arrives can delay computation and cause deadline misses.
The periodic schedule makes the next update time known in advance, allowing restoration to be planned before demand.
We present \systemname, a serving system for multiplexing GPU memory across periodic interaction sessions.
Through cyclic KV restoration, \systemname reuses space released by idle sessions to prepare other sessions for their next updates.
It coordinates these restorations with session execution, accounting for both shared transfer capacity and GPU memory availability.
