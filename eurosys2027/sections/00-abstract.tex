\begin{abstract}
Emerging interaction models sustain long-lived full-duplex sessions in which input and output overlap.
In periodic service, a model processes newly accumulated input in fixed-duration micro-turns and decides whether and when to respond.
After a micro-turn finishes, its historical key--value (KV) state can remain idle until the next update, yet still occupy GPU memory.
As retained history grows, full residency can exhaust GPU capacity while the combined work of admitted sessions still leaves time within each period.
Offloading idle KV frees capacity, but restoring it on demand puts recovery on the next update's critical path.
The periodic schedule provides advance notice of the next update, making it possible to plan restoration before demand.
We present the design of \systemname, a serving system for memory multiplexing through cyclic KV restoration, without truncating the history retained by the application.
Where the application permits, \systemname staggers session phases, evicts recoverable KV after use, and schedules its restoration from host memory before the next update.
Space released by one session can then accommodate another session's restoration.
The plan limits eviction to the volume that the shared link can restore in time and accounts for each restoration's full GPU allocation before copying begins.
