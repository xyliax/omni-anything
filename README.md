# omni-anything：双工语音 serving 的显存墙与"带宽换显存"传送带

单卡上 serve"双工语音前台（480ms 硬拍）+ 后台 agent 工具结果回注"负载的研究：真实 GPU 微基准标定 + 保真度已验证的离散事件模拟，收敛到一个方案候选——**时刻表化的尾部 KV 传送带（用 H2D 带宽换等效显存容量）**。

## 主线（一段话）

双工语音 serving 是显存绑定的：KV 每拍必被 attend、常驻单调涨、无轮次间隙可换出，GPU 在时间占用仅 ~13–32% 时就因装不下而死（本仓库 S1 + Metronome 交叉验证）。既然容量稀缺而拍内 H2D 带宽和计算时间大量闲置，就用带宽赎回容量：尾部 KV 母本住 DRAM、按时刻表每拍 DMA 搬入、算完即释放——等效容量 = M + P，收益比 P/M 是纯硬件比值（PCIe5/480ms 净 ~20%，3090/PCIe3 +83%，2s 拍 ~+100%）。相位指派、传输时刻表、提交/作废语义、静默停泊四个编排对象构成方案主体。
