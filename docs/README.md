# Research documents

This directory contains project facts, design decisions, and research history. Documents have
different authority; the table below prevents historical narrative or unverified design from being
mistaken for current evidence.

| Document | Authority | Read it for |
| --- | --- | --- |
| [`FINDINGS.md`](FINDINGS.md) | Current conclusions | Verified findings and evidence pointers |
| [`PROBLEM.md`](PROBLEM.md) | Current problem definition | Workload, bottlenecks, and solution boundary |
| [`PAPER-EXPERIMENTS.md`](PAPER-EXPERIMENTS.md) | Active experiment plan | Claims, E0-E6 matrix, methodology, execution record |
| [`IDEA-KV-CONVEYOR.md`](IDEA-KV-CONVEYOR.md) | Design history | Conveyor derivation and predictions superseded by E2/E3 |
| [`STORY.md`](STORY.md) | Historical narrative | Discovery process and still-relevant related work |
| [`METRONOME-NOTE.md`](METRONOME-NOTE.md) | Third-party usage notes | Why and how the Metronome pin is used |

For executable code and current implementation status, use [`../experiments/README.md`](../experiments/README.md).
For evidence layout and run lookup, use [`../results/README.md`](../results/README.md).
